# 🌍 Air Quality in India – EDA & Data Visualization

An exploratory data analysis project that investigates **air pollution across major Indian cities** using AQI and pollutant measurements.

## 📌 Project Overview

The project includes:

- Data cleaning
- Missing-value handling
- AQI category analysis
- Pollutant correlation analysis
- City-level pollution comparison
- Seasonal and yearly trends
- Data visualizations

## 📊 Dataset

The dataset contains:

```text
29,531 rows
16 original columns
```

Main features include:

- PM2.5
- PM10
- NO / NO2 / NOx
- CO
- SO2
- O3
- AQI
- AQI Category

## 🧹 Data Preparation

The notebook:

- Converts dates to datetime
- Fills missing numerical values
- Reconstructs missing AQI categories
- Creates Year, Month, Season, and Weekend features

## 📈 Analysis

The project visualizes:

- AQI distribution
- Top polluted cities
- Cleanest cities
- Pollutant correlations
- Yearly AQI trends
- Seasonal AQI patterns
- Weekday vs. weekend AQI

## 🔎 Key Findings

- **PM10** is strongly related to AQI
- **PM2.5 and PM10** are highly correlated
- Pollution varies significantly between cities
- AQI shows clear seasonal patterns
- Most observations are **Moderate** or **Satisfactory**
